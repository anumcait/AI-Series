# 🚀 Day 1 — AI Bug Description Clarifier

The first project focuses on improving the quality of developer-reported bug descriptions.

## Problem

Developers often report bugs informally, for example:

> "App keeps crashing when I click save."

Such descriptions may not provide enough structure for developers to quickly understand or reproduce the issue.

## Solution

The AI Bug Description Clarifier uses an LLM to transform an informal bug report into a structured and professional issue summary.

### Flow

```text
Raw Bug Description
        ↓
   AI Prompt
        ↓
    LLM / OpenAI
        ↓
Structured Bug Summary
```

## Example

### Input

```text
App keeps crashing when I click save.
```

### Output

```text
Bug Summary:
Application crashes upon clicking the "Save" button.

Triggering Action:
User clicks the "Save" button.

Observed Behavior:
The application unexpectedly crashes after the "Save" button is clicked.
```

## Technologies Used

- Python 🐍
- OpenAI API 🤖
- Prompt Engineering
- Virtual Environment

# 🚀 Day 2 — AI Travel Guide Chatbot

The second project focuses on building a simple AI-powered chatbot using the OpenAI API.

## Problem

Traditional travel applications often provide predefined information. They may not provide a natural conversational experience for users who want to start planning a trip.

## Solution

The AI Travel Guide Chatbot uses an LLM to act as a friendly travel guide.

The chatbot starts the conversation by greeting the user and asking where they want to go.

## Flow

```text
User
  ↓
Prompt
  ↓
OpenAI API
  ↓
GPT-4.1-mini
  ↓
AI Travel Guide Response
```

## Example

### Prompt

```text
You are a friendly travel guide. Greet the user and ask where they want to go.
```

### Example Output

```text
Hello, traveler! I'm your friendly travel guide. Where would you like to go?
```

The exact response can vary because it is generated by the AI model.

## Technologies Used

- Python 🐍
- OpenAI API 🤖
- GPT-4.1-mini
- Prompt Engineering
- Virtual Environment
- Environment Variables

## 🔑 Key Concepts Learned

- Creating an OpenAI client
- Using an API key and base URL
- Reading credentials from environment variables
- Sending prompts to a chat model
- Using the `openai/gpt-4.1-mini` model
- Understanding chat messages and roles
- Controlling model output with `temperature`
- Limiting generated output with `max_tokens`
- Extracting generated text from the API response
- Running an OpenAI project inside a Python virtual environment
