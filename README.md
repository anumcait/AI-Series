# 🚀 Day 1 — AI Bug Description Clarifier

The first project focuses on improving the quality of developer-reported bug descriptions.

## Problem

Developers often report bugs informally, for example:

> "App keeps crashing when I click save."

Such descriptions may not provide enough structure for developers to quickly understand or reproduce the issue.

## Solution

The AI Bug Description Clarifier uses an LLM to transform an informal bug report into a structured and professional issue summary.

### Flow

```text
Raw Bug Description
        ↓
   AI Prompt
        ↓
    LLM / OpenAI
        ↓
Structured Bug Summary
```

## Example

### Input

```text
App keeps crashing when I click save.
```

### Output

```text
Bug Summary:
Application crashes upon clicking the "Save" button.

Triggering Action:
User clicks the "Save" button.

Observed Behavior:
The application unexpectedly crashes after the "Save" button is clicked.
```

- Python 🐍
- OpenAI API 🤖
- Prompt Engineering
- Virtual Environment

# 🚀 Day 3 — AI Comment Generator

The third project focuses on using Generative AI to automatically generate meaningful comments or docstrings for source code.

## Problem

Code can become difficult to understand and maintain when its purpose is not clearly documented.

For example:

```python
def calculate_area(length, width):
    return length * width
```

Although the function is simple, a meaningful comment can make its purpose immediately clear.

Writing documentation manually for every function can also become repetitive, especially in larger projects.

## Solution

The AI Comment Generator uses an LLM to analyze a provided code snippet and generate a concise, one-line comment or docstring explaining its purpose.

### Flow

```text
Code Snippet
     ↓
Dynamic AI Prompt
     ↓
OpenAI API
     ↓
GPT-4.1-mini
     ↓
Generated Comment / Docstring
```

## Example

### Input

```python
def calculate_area(length, width):
    return length * width
```

### Output

```text
# Calculates the area using the given length and width.
```

The exact wording may vary because the response is generated by the AI model.

## 🧠 How It Works

The Python program accepts a code snippet through the `generate_comment()` function.

The code is inserted into a dynamically constructed prompt that instructs the AI model to generate a clear and concise explanation.

The prompt is then sent to `openai/gpt-4.1-mini` through the OpenAI API.

The generated response is extracted from the API response, printed to the console, and returned by the function.

## Technologies Used

- Python 🐍
- OpenAI API 🤖
- GPT-4.1-mini
- Prompt Engineering
- Python Virtual Environment
- Environment Variables

## 🔑 Key Concepts Learned

- Creating an OpenAI client
- Using API keys securely through environment variables
- Configuring a custom API base URL
- Creating reusable Python functions
- Using function parameters for dynamic input
- Building parameterized prompts
- Sending messages to an AI chat model
- Understanding `user` message roles
- Using `max_tokens` to control output length
- Using `temperature` to control response variability
- Extracting generated content from an API response
- Printing and returning AI-generated output


## ▶️ Running the Project

```bash

```

The program sends the test code to the AI model and displays the generated comment in the terminal.

# 🚀 Day 4 — AI Comparison Lab

The fourth project focuses on using Generative AI to compare the chipsets used in two iPhone models and return a concise, one-word result.

## Problem

Comparing technical specifications between products can require manually checking information from different sources.

For example, when comparing two iPhone models, we may only want to know the chip used in each model rather than receiving a long specification comparison.

## Solution

The AI Comparison Lab uses an LLM to compare two given iPhone models through a parameterized prompt.

The program compares:

- iPhone 13
- iPhone 17

The AI is instructed to return only the chip name used in the second model.

### Flow

```text
iPhone 13 + iPhone 17
        ↓
Parameterized AI Prompt
        ↓
OpenAI API
        ↓
GPT-4.1-mini
        ↓
One-Word Result
```

## Example

### Input

```python
response = compare("iphone 13", "iphone 17")
```

### Output

```text
A17
```

The exact response is generated by the AI model based on the prompt.

## 🧠 How It Works

The Python program defines a reusable `compare()` function that accepts two parameters.

The model names are inserted dynamically into a prompt using an f-string.

The prompt instructs the AI to compare only the chips and return the chip name of the second model as one word without explanation or punctuation.

The prompt is then sent to `openai/gpt-4.1-mini` using the OpenAI API.

The generated response is extracted, cleaned with `strip()`, printed to the console, and returned by the function.

## Technologies Used

- Python 🐍
- OpenAI API 🤖
- GPT-4.1-mini
- Prompt Engineering
- Python Virtual Environment
- Environment Variables

- Controlling output with `max_tokens`
- Controlling response variability with `temperature`
- Extracting content from an API response
- Printing and returning AI-generated output

# 🚀 Day 5 — AI Converter Lab

The fifth project focuses on using Generative AI to transform a paragraph into concise, easy-to-read bullet points.

## Problem

Long paragraphs can contain useful information but may take time to read and understand.

For example, when working with technical or business information, we may want to quickly extract the main ideas instead of reading the entire paragraph.

## Solution

The AI Converter Lab uses an LLM to convert a given paragraph into short, meaningful bullet points through a parameterized prompt.

The program converts information about:

- Artificial Intelligence
- Automation
- Decision-making
- Innovation
- Healthcare, finance, and education

### Flow

```text
Paragraph
    ↓
Parameterized AI Prompt
    ↓
OpenAI API
    ↓
GPT-4.1-mini
    ↓
Concise Bullet Points
```

## Example

### Input

```python
text = """Artificial Intelligence is transforming industries by automating tasks, improving decision-making, and enabling new innovations across healthcare, finance, and education."""

response = convert_to_bullets(text)
```

### Output

```text
- AI automates tasks across industries
- Enhances decision-making processes
- Drives innovations in healthcare, finance, and education
```

The exact response is generated by the AI model based on the prompt.

## 🧠 How It Works

The Python program defines a reusable `convert_to_bullets()` function that accepts one parameter, `text`.

The paragraph is inserted dynamically into a prompt using an f-string.

The prompt instructs the AI to convert the paragraph into short, meaningful, and easy-to-read bullet points.

The prompt is then sent to `openai/gpt-4.1-mini` using the OpenAI API.

The generated response is returned by the function, stored in the `response` variable, and printed to the console.
