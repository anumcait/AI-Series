# 🚀 Day 3 — AI Comment Generator

The third project focuses on using Generative AI to automatically generate meaningful comments or docstrings for source code.

## Problem

Code can become difficult to understand and maintain when its purpose is not clearly documented.

For example:

```python
def calculate_area(length, width):
    return length * width
```

Although the function is simple, a meaningful comment can make its purpose immediately clear.

Writing documentation manually for every function can also become repetitive, especially in larger projects.

## Solution

The AI Comment Generator uses an LLM to analyze a provided code snippet and generate a concise, one-line comment or docstring explaining its purpose.

### Flow

```text
Code Snippet
     ↓
Dynamic AI Prompt
     ↓
OpenAI API
     ↓
GPT-4.1-mini
     ↓
Generated Comment / Docstring
```

## Example

### Input

```python
def calculate_area(length, width):
    return length * width
```

### Output

```text
# Calculates the area using the given length and width.
```

The exact wording may vary because the response is generated by the AI model.

## 🧠 How It Works

The Python program accepts a code snippet through the `generate_comment()` function.

The code is inserted into a dynamically constructed prompt that instructs the AI model to generate a clear and concise explanation.

The prompt is then sent to `openai/gpt-4.1-mini` through the OpenAI API.

The generated response is extracted from the API response, printed to the console, and returned by the function.

# 🚀 Day 6 — Use AI as an Email Assistant

The sixth project focuses on using Generative AI to transform informal messages into polite and professional emails.

## Problem

People often write quick messages using informal language, abbreviations, or a direct tone.

For example:

```text
hey send me that report asap
```

Although the meaning is understandable, the message may not be appropriate for professional communication.

## Solution

The AI Email Assistant uses an LLM to rewrite an email while preserving its original meaning and improving the tone, wording, and professionalism through a parameterized prompt.

The program improves:

- Email tone
- Professional wording
- Politeness
- Clarity
- Communication style

### Flow

```text
Informal Email
      ↓
Parameterized AI Prompt
      ↓
OpenAI API
      ↓
GPT-4.1-mini
      ↓
Professional Email
```

## Example

### Input

```python
text = "hey send me that report asap"

response = rewrite_email(text)
```

### Output

```text
Could you please send me that report as soon as possible? Thank you.
```

The exact response is generated by the AI model based on the prompt.

## 🧠 How It Works

The Python program defines a reusable `rewrite_email()` function that accepts one parameter, `text`.

The email text is inserted dynamically into a prompt using an f-string.

The prompt instructs the AI to rewrite the message politely and professionally while preserving its original meaning.

The prompt is then sent to `openai/gpt-4.1-mini` using the OpenAI API.

The generated response is returned by the function, stored in the `response` variable, and printed to the console.

## Technologies Used

- Python 🐍
- OpenAI API 🤖

## ⚙️ Setup

Create a Python virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Install the OpenAI package:

```bash
pip install openai
```

Load the API configuration:

```bash
source /root/.bash_profile
```

The application reads:

```text
OPENAI_API_KEY
OPENAI_API_BASE
```

## OpenAI Client

The Python application creates the client using the environment variables:

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY"),
    base_url=os.environ.get("OPENAI_API_BASE"),
)
```

This allows the application to authenticate with the OpenAI-compatible API without placing the API key directly in the source code.

## Parameterized Prompt

The email is dynamically inserted into the prompt:

```python
prompt = f"""Rewrite the following email politely and professionally.
Preserve the original meaning while improving the tone and wording.

Email:
{text}
"""
```

The `{text}` value changes depending on the email supplied to the function.

## AI Request

The prompt is sent to the chat model using:

```python
response = client.chat.completions.create(
    model="openai/gpt-4.1-mini",
    messages=[{"role": "user", "content": prompt}],
    max_tokens=60,
    temperature=0.1,
)
```

Here:

- `model` specifies the AI model.
- `messages` contains the user prompt.
- `max_tokens=60` limits the generated response.
- `temperature=0.1` keeps the response controlled and consistent.
- `response` stores the API result.

The generated email is obtained from:

```python
response.choices[0].message.content
```

# 🚀 Day 8 — Generate Haikus with AI

The eighth project focuses on using Generative AI to create short-form poetry in the traditional **5-7-5 haiku structure**.

## Problem

Generating a correctly structured haiku requires the poem to contain three lines with a specific syllable pattern:

```text
Line 1 → 5 syllables
Line 2 → 7 syllables
Line 3 → 5 syllables
```

We want an AI model to generate a haiku automatically based on a topic supplied by the user.

For this project, the topic is:

```text
sky
```

## Solution

The AI Haiku Generator accepts a topic and sends a parameterized prompt to an OpenAI-compatible AI model.

The model is instructed to generate exactly three lines following the **5-7-5 syllable pattern**.

### Flow

```text
Topic
  ↓
Parameterized AI Prompt
  ↓
OpenAI API
  ↓
GPT-4.1-mini
  ↓
Three-Line Haiku
```

## Example

### Input

```python
response = generate_haiku("sky")
```

### Output

```text
Blue sky spreads above
Soft clouds drift across the blue
Sun warms earth below
```

The exact haiku is generated by the AI model.

## 🧠 How It Works

The Python program defines a reusable `generate_haiku()` function that accepts a topic.

The topic is dynamically inserted into a parameterized prompt using an f-string.

The prompt instructs the AI to:

- Generate a haiku about the supplied topic
- Produce exactly three distinct lines
- Use 5 syllables on the first line
- Use 7 syllables on the second line
- Use 5 syllables on the third line
- Return only the haiku
- Avoid titles, numbering, explanations, or additional text

The prompt is then sent to `openai/gpt-4.1-mini` using the OpenAI API.
