# Day 11 — AI Sentiment Classifier

## AI Sentiment Classifier

The AI Engineering team wants to automatically analyze customer reviews and determine whether the customer setiment is positive, Neutral, or Negative.

Your task is to build a python application that uses an AI model to classify a customer review and provide a short explanation.

This is self-designed Practice Lab.

---

## Objective

Build a python-based **AI Sentiment Classifier** that:

1. Accepts a customer review.
2. Sends the review to an AI model.
3. Classifies the review as Positive, Neutral, or Negative.
4. Provides a short explanation for the classification.
5. Prints the result to the console.

---

## Scenario

A company receives hundreds of customer reviews every day.

Instead of manually reading and categorizing every review, the company wants to use an AI model to automatically identify the sentiment of each review.

---

## Task

Create a Python file named:

```text
sentiment_classifier.py
```

The file should contain a function:

```python
def classify_sentiment(review: str) -> str:
    ...
```

The function must accept the customer review dynamically.

It should construct a prompt that instructs the AI model to classify the review into one of the following categories:

```text
Positive
Neutral
Negative
```

The AI should also provide a short explanation.

---

## Input

Use the following customer review for the first test:

```text
The product arrived quickly and works perfectly.
```

---

## Expected Output

The response should follow this general format:

```text
Sentiment: Positive
Explanation: The customer is satisfied with the product and its delivery.
```

The exact explanation may vary because it is generated by the AI model.

---

## Requirements

- Use Python.
- Use an AI model.
- Use an environment variable for the API key.
- Do not hardcode the API key.
- Create an OpenAI-compatible or Gemini AI client.
- Create a function named `classify_sentiment`.
- The function must accept `review` as a parameter.
- The prompt must use the supplied review dynamically.
- The AI must classify the review as Positive, Neutral, or Negative.
- The AI must provide a short explanation.
- Print the final response to the console.

## AI Model

For this lab, use the Gemini API.

Suggested model:

```text
gemini-3.8-flash
```

The model name may change over time. If the API reports that the model is unavailable, check the current Gemini documentation for an available model.

## API Configuration

Use an environment variable for the Gemini API key:

```text
GEMINI_API_KEY
```

Your Python application should read the key from the environment rather than placing the key directly in the source code.

Example:

```python
import os

api_key = os.environ.get("GEMINI_API_KEY")
```

Do not commit your API key to GitHub.

## Environment Setup

From the project root:

```bash
cd /d/AI-Engineering
```

Create a virtual environment:

```bash
python3 -m venv venv
```

On Windows Git Bash, activate it with:

```bash

```

Install the Gemini Python SDK:

```bash

```

Set your API key:

```bash
export GEMINI_API_KEY="your-api-key"
```

Verify that the environment variable exists without displaying
the actual key:

```bash
if [ -n "$GEMINI_API_KEY" ]; then
    echo "GEMINI_API_KEY is set"
else
    echo "GEMINI_API_KEY is missing"
fi
```

## Prompt Requirements

Your prompt should clearly tell the AI:

- What task it needs to perform.
- Which sentiment categories are allowed.
- That the supplied review should be analyzed.
- That a short explanation should be provided.
- What output format you expect.

The customer review must be inserted into the prompt dynamically.

For example, conceptually:

```text
Review
  ↓
Prompt
  ↓
AI Model
  ↓
Sentiment + Explanation
```

Do not simply hardcode the review inside your classification
function.

## Troubleshooting

If the application fails, investigate the problem before looking for a complete solution.

Check:

- Is the virtual environment activated?
- Is `google-genai` installed?
- Is `GEMINI_API_KEY` available?
- Is the API key valid?
- Is the selected model available?
- Is the AI client configured correctly?
- Is the prompt being constructed correctly?
- Is the review being passed dynamically?
- Is the API response being accessed correctly?
- Does the returned response match the requested format?

If you receive a `404 NOT_FOUND` error, check whether the
model name is currently available for your account.
